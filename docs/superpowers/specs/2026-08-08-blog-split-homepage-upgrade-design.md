# Blog 拆分与首页升级设计

日期：2026-08-08
状态：已批准
范围：agent_engineer 前端

## 背景

当前首页把博客展示、筛选和完整文章内容都放在同一个长页面里，访问者需要在浏览文章时不断滚动，且首页同时承担“介绍”和“阅读”两个职责。我们希望把文章浏览拆到独立页面，同时把首页升级得更高级、更吸睛，并保留现有乐高积木视觉语言。

## 目标

- 新增独立博客浏览页 `/browse`，采用“双栏书房”结构。
- 新增独立文章页 `/post/:id`，支持分享和返回。
- 首页改为“轻量门面”：Hero、数据统计、最近精选、成长路线、CTA。
- 保留成长路线，并预留 AI 能力评测入口（本次不实现评测功能）。
- 引入更多组件和高质量图片素材，提升视觉质感，但保持乐高积木风格。

## 非目标

- 不实现 AI 能力评测本身，只做入口和视觉占位。
- 不重构后端业务分层。
- 不重写现有 AI 助理、登录、写作流程。

## 方案选择

已确认采用方案 A：轻量门户 + 双栏书房 + 独立文章页。

对比过的备选方案：

- 方案 B：视觉重做优先，动效和组件更多，但加载更重、装饰感更强。
- 方案 C：最小拆分，只拆文章列表，不做视觉升级。

## 路由结构

```text
/              首页：轻量门面
/browse        书房：双栏浏览页
/post/:id      独立文章页
/assistant     AI 助理（保留）
/login         登录（保留）
/new           写文章（保留）
```

## 页面设计

### 首页 `/`

- Hero：全屏真实图片背景，保留“A BLOG BUILT LIKE A BRICK SET”眉标，标题、简介、两个主入口：浏览文章、问我的笔记。
- 数据统计条：文章数、分类数、知识块数、总字数，使用真实接口数据。
- 最近精选：展示最新 6 篇文章卡片，摘要和标签，点击进入 `/post/:id`；桌面 3 列，移动端 1 列。
- 成长路线：4 个成长步骤卡片 + 一个 AI 评测入口卡片，标注“即将上线”，不伪造功能。
- CTA：引导访问者去 `/assistant` 提问。
- 首页不再展示完整文章正文。

### 书房 `/browse`

- 左侧常驻侧栏：搜索、全部分类、领域入口、文章数量。
- 右侧主区：文章卡片列表，显示标题、摘要、标签、日期，点击进入 `/post/:id`。
- 支持 `/browse?tag=<tag>`，从首页或外部链接进入时自动带筛选。
- 移动端侧栏折叠为顶部搜索和横向分类条。

### 独立文章页 `/post/:id`

- 面包屑式返回入口：返回书房，保留进入前的筛选上下文。
- 标题、标签、日期、Markdown 正文渲染。
- 登录状态下保留删除入口。
- 底部展示同领域相关文章，同领域按共享标签判断，最多 3 篇。
- 加载中、加载失败、文章不存在三种状态都有明确反馈。

## 前端组件与 API

### 新增页面

- `BlogBrowse.vue`：书房双栏页面。
- `PostView.vue`：独立文章页。

### 调整页面

- `Home.vue`：移除完整文章列表，改为轻量门面。
- `App.vue`：导航加入“书房”，footer 链接指向 `/browse` 和 `/post/:id`。
- `router/index.ts`：新增 `/browse` 和 `/post/:id` 路由。

### API

- `api/posts.ts` 新增 `fetchPost(id)`，复用后端已有 `GET /posts/{post_id}`。
- 书房和首页继续使用 `fetchPosts()`。

## 数据流

1. 首页挂载后调用 `fetchPosts()`，计算统计、最近精选和分类数据。
2. 书房挂载后调用 `fetchPosts()`，本地完成搜索与分类筛选；点击文章跳转 `/post/:id`。
3. 文章页按路由参数调用 `fetchPost(id)`，展示正文和元信息。
4. 删除文章后返回书房并刷新列表。

## 错误处理

- 首页加载失败：显示错误提示，保留其他静态区块。
- 书房加载失败：显示错误提示和重试入口。
- 文章页加载失败：显示失败状态和返回书房按钮。
- 文章不存在：显示“文章不存在”状态，不出现空白页。
- 删除失败：沿用现有 confirm 流程并提示失败。

## 视觉与组件清单

- 保留乐高积木设计系统：红、蓝、黄、绿、紫五色，黑色描边，硬阴影，小圆角。
- 引入 Aceternity 风格组件灵感：Spotlight 卡片、网格背景、Marquee 信息流、Bento 非对称网格。
- 新增高质量图片素材：Hero 背景和精选卡片图片，使用乐高/AI Agent 主题，避免与现有素材重复。
- 组件只做视觉增强，不遮挡文字，不在页面里加入说明性文案。
