# 在fastapi中看见@app.get(/1)而产生的疑问

值得注意的是，在python中，函数也是对象：
```
def hello():
    print("Hello")

a = hello
a()
```
由此获得的输出是：
```
Hello
```

既然函数是“对象”，对象可以被当做参数传到函数里，也能当返回值，那么函数也可以，那么：
```
def decorator(func):

    def wrapper():
        print("开始")

        func()

        print("结束")

    return wrapper

def hello():
    print("Hello")

hello = decorator(hello)

hello()
```
输出：
```
开始

Hello

结束
```
在hello函数没有做更改的情况下，我们通过这种方式实现了给hello加功能，这个就是装饰器的本质，它实际上利用函数是对象的特性实现了在函数外给某个函数加了个额外功能

而 @app.get(/1) 就很好理解了，相当于是给修饰的函数装上了一个路由，每次有人访问"https://127.0.0.1/1" 的时候就调用被修饰器修饰的函数(这里的get指的是get请求的意思)
