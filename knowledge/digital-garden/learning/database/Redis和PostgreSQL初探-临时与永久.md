# 为什么项目里会用不止一种数据库？

Redis是：内存数据库

PostgreSQL像：

📚 图书馆。

数据永久保存。

---

Redis像：

📝 便利贴。

贴桌子上很快，但是掉电

可能没了

---

所以AI Agent通常：

```
用户资料

↓

PostgreSQL
```

---

但是：

```
聊天缓存

↓

Redis
```

---

例如用户连续问：

```
你好

↓

今天怎么样？

↓

帮我总结一下
```

最近几分钟聊天记录放Redis

速度极快

---

以后真正保存聊天历史。

再写进PostgreSQL。
