# 泛型阅读三步法

第一次看到这种代码时，我的内心是拒绝的：

```ts
export async function fetchPosts(): Promise<Post[]> {
  const { data } = await axios.get<Post[]>('/api/posts')
  return data
}
```

后来发现，泛型没有那么可怕。它只是“类型的参数”，用对了方法，读起来可以很快。

## 1. 先看这段代码的整体意思

```text
定义一个异步函数 fetchPosts
它最后会返回一个 Promise，Promise 里装的是 Post 数组
函数内部：请求 GET /api/posts，并把响应里的 data 当成 Post 数组拿出来
```

## 2. 泛型的本质：类型的填空位

普通函数有参数：

```ts
function echo(value) { return value }
echo("hello")
```

泛型就是让类型也能当参数填：

```ts
function echo<T>(value: T): T { return value }
echo<string>("hello")
```

`<T>` 的意思是：这里留一个类型空位，调用时再填。填什么，函数里所有 `T` 就都变成什么。

所以：

```ts
Promise<Post[]>          // 一个装着 Post 数组的 Promise
axios.get<Post[]>(...)   // 告诉 axios：响应里的 data 是 Post 数组
ref<Post[]>([])          // 一个装着 Post 数组的 ref
```

## 3. 泛型阅读三步法

1. 先找到 `<...>`，把它当成“这个容器里装什么”。
2. 从最外层往里读：`Promise<Post[]>` 外面是 Promise，里面是 Post 数组；`axios.get<Post[]>` 外层是 axios.get 这个调用，里面规定 data 是 Post 数组。
3. 遇到 `T` 这种单字母不要慌，它只是占位符，含义由上下文决定。重点永远是：同一个 `T` 出现的地方，类型必须一致。

## 4. 一个更直观的例子

```ts
function first<T>(items: T[]): T | undefined {
  return items[0]
}

const nums = first<number>([1, 2, 3])   // T = number，返回 number | undefined
const names = first<string>(["a", "b"]) // T = string，返回 string | undefined
```

`first` 不需要关心数组里是数字还是字符串，它只负责返回第一个。泛型让它既能服务数字，又能服务字符串，而且类型还是安全完整的。

## 5. 一个口诀

```text
Promise<X>    = 异步结果最终是 X
axios.get<X>  = 响应里的 data 是 X
ref<X>(初始值) = 这个响应式变量装的是 X
X[]           = X 的数组
```

## 6. 以后怎么练

- 在 VS Code 里把鼠标放到函数或变量上，IDE 会显示推断出来的类型，边看边对照。
- 遇到不认识的泛型，先读最外层，再读 `< >` 里装的类型，不用背语法。
- Vue 里最常见的三个泛型是 `ref<T>`、`axios.get<T>`、`Promise<T>`，把它们看熟，整个前端阶段就够用了。

## 面试一句话总结

泛型是类型的参数；`Promise<X>` 表示异步结果最终是 X，`axios.get<X>` 表示响应 data 是 X；读泛型的顺序永远是从最外层容器，读到尖括号里装的类型。
