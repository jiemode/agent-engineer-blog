# Agent Engineer Blog 项目地图

这个项目不是“又一个博客”，而是一条把 AI Agent 常见技术点全部亲手跑通的成长线：
FastAPI 分层后端、JWT 登录、Markdown 发布、RAG 知识库、流式 AI 助理、异步任务引擎、GitHub Pages + Render + Neon 部署。

## 一句话总结

我用 Vue 3 做了一个乐高风个人博客，用 FastAPI 做了分层后端，
再给博客加上 JWT 登录、RAG 笔记问答、流式 AI 助理和异步任务，
最后通过 GitHub Actions、Render 和 Neon 把它免费部署上线。
