## 第一组：项目开场

> 用户写 Markdown 文章、JWT 登录、RAG 知识库问答、流式 AI 助理、异步摘要任务，
> 然后通过 GitHub Actions、Render、Neon 免费部署上线。

### 3. 这个项目是你一个人做的吗？

诚实回答：

## 第二组：架构与 FastAPI

### 4. 为什么用 FastAPI 不用 Flask？

要点：异步原生、Pydantic 校验、自动文档、依赖注入。

### 5. Router、Service、Core 各管什么？

要点：

- Router：HTTP 传话筒，不知道业务细节。
- Service：业务流程导演，编排核心组件。
- Core：可复用基础设施，比如数据库、LLM、RAG。

### 6. 换数据库你会改哪里？

> 只改 `core/database.py` 的 `DATABASE_URL`，以及对应的连接参数。
> 业务代码不关心底层数据库，因为 Service 只依赖 Session。

### 7. Pydantic 漏字段为什么会 422？

> FastAPI 在进入路由函数前用 Pydantic 校验请求体，字段缺失或类型不对就返回 422。

### 8. Depends 是什么？

> 依赖注入。路由声明 `session: Session = Depends(get_session)`，
> 框架负责在请求时创建会话、请求结束自动关闭。

## 第三组：安全

### 9. JWT 和 Session 登录有什么区别？

要点：JWT 无状态，服务器不存会话；Session 有状态，服务端要存。

### 10. JWT 安全吗？有没有风险？

要点：JWT 是签名不是加密，payload 可以被解码；必须用 HTTPS 传输；
密钥要放环境变量；过期时间不能太长。

### 11. 密码为什么不能明文存？

> bcrypt 是单向哈希，数据库泄露也不会直接暴露明文。

### 12. 登录流程怎么走？

> 用户名密码 → 查用户 → bcrypt 验证 → 签发 JWT → 前端存 token →
> 后续请求带 `Authorization: Bearer <token>` → 后端验签。

## 第四组：RAG 与 Agent

### 13. RAG 是什么？

> Retrieval-Augmented Generation，先检索相关资料，再让大模型基于资料生成回答。

### 14. 为什么检索结果不好？

要点：

- 切块策略不好：太长/太短/没有重叠。
- 分词不精确：中文歧义、专有名词。
- 评分太简单：只有词频，没有向量语义。
- 资料本身太少或太旧。

### 15. 你怎么防止 AI 编造？

要点：

- 只允许基于检索资料回答。
- 返回出处，让用户可追溯。
- 检索不到时明确说“没找到”，而不是硬编。

### 16. 为什么资料要切块？

> 控制上下文长度、降低 token 成本、避免无关内容干扰、让检索粒度更精细。

### 17. 单 Agent 和多 Agent 怎么选？

> 先单 Agent 跑通闭环，再按职责拆多 Agent。拆的收益是职责和提示词聚焦，
> 代价是编排和流式复杂度上升。我的项目现阶段单 Agent 就够。

## 第五组：异步任务

### 18. 为什么不能直接在接口里跑 AI 任务？

> HTTP 请求不能等几十秒。任务应该入队，Worker 后台执行，前端轮询状态。

### 19. 任务状态机是什么？

> PENDING → RUNNING → SUCCEEDED / FAILED。

### 20. 你的 Worker 挂了怎么办？

诚实回答：

> 当前是学习版，没有心跳和重试。工业级方案是 Redis Stream、多 Worker、
> 心跳检测、死信队列、失败重试和定时清理。

## 第六组：部署

### 21. GitHub Pages 首页空白怎么排查？

> 先看 Vue Router base 是否正确；子路径部署要设置
> `createWebHistory(import.meta.env.BASE_URL)`。

### 22. 前端怎么调后端？

> 开发环境 Vite 代理 `/api`，生产环境用环境变量 `VITE_API_BASE_URL` 指向 Render。

### 23. CORS 是什么？

> 浏览器安全机制。前端在 GitHub Pages、后端在 Render，跨域请求需要后端允许来源。

### 24. 密钥放哪里？

> 不放代码。开发放 `.env`，生产放 Render/Neon 环境变量，`.env` 要进 `.gitignore`。

## 第七组：前端

### 25. ref 和 computed 的区别？

> ref 是响应式数据盒子；computed 是根据已有数据自动计算的只读派生值。

### 26. axios 拦截器有什么用？

> 统一加 token、统一处理 401、统一错误提示，不用每个接口重复写。

### 27. 为什么 TypeScript 泛型有用？

> `Promise<Post[]>` 和 `axios.get<Post[]>` 让代码知道数据长什么样，
> 编辑器能提前发现类型错误。

## 第八组：开放题

### 28. 如果让你把这个博客做成商业产品，第一步做什么？

推荐回答：

> 先把鉴权和内容权限做扎实：区分读者、作者、管理员；
> 然后做内容安全、用量控制、审计日志，最后再考虑付费和团队协作。

### 29. 如果让你升级 RAG，你怎么做？

> 换 embedding 向量检索，加混合检索和重排序；按语义切块而不是纯按长度；
> 加增量更新和检索效果评估。

### 30. 你还有什么问题想问我们？

好的反问：

- 这个团队现在最想解决的 Agent 技术难点是什么？
- 你们怎么评估 Agent 的回答质量？
- 这个岗位入职后前三个月的目标是什么？
