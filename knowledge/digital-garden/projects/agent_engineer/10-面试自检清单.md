# 面试自检清单

## 使用方法

每题 30 秒内能说清“是什么 + 为什么 + 我怎么做”就算过。
说不清的，回到对应笔记补一遍。

## A. 架构

- [ ] 你能 30 秒讲完项目吗？
- [ ] 你能画出 Router → Service → Core 的调用链吗？
- [ ] 你能说出分层解决了什么问题吗？
- [ ] 换数据库你要改哪些文件？
- [ ] 加一个新接口，你的步骤是什么？

## B. FastAPI / Python

- [ ] FastAPI 为什么适合 Agent 项目？
- [ ] Pydantic 校验失败会返回什么？
- [ ] `Depends` 和依赖注入怎么解释？
- [ ] lifespan 的 `yield` 上下分别做什么？
- [ ] 装饰器是什么？`@app.get` 是怎么工作的？

## C. 数据库

- [ ] SQLModel 和 Pydantic 的区别？
- [ ] Model 和 Schema 为什么分开？
- [ ] 外键、索引、唯一约束在项目里哪里体现？
- [ ] SQLite 和 PostgreSQL 有什么区别？

## D. 安全

- [ ] 为什么密码用 bcrypt？
- [ ] JWT 三个部分是什么？
- [ ] `sub`、`iat`、`exp` 分别代表什么？
- [ ] JWT 和 Session 有什么区别？
- [ ] 密钥应该放在哪里？

## E. RAG

- [ ] RAG 是什么？
- [ ] 为什么要切块？重叠有什么用？
- [ ] 倒排索引是怎么建的？
- [ ] 检索不到资料时 AI 应该怎么做？
- [ ] 如果检索效果差，你会怎么排查？

## F. Agent

- [ ] Agent 最小循环是什么？
- [ ] 单 Agent 和多 Agent 怎么选？
- [ ] 上下文记忆是怎么传的？
- [ ] 工具调用在你的项目里指什么？

## G. 异步任务

- [ ] 为什么长任务不能同步做？
- [ ] 任务状态机是什么？
- [ ] Worker 怎么拿到任务？
- [ ] 生产环境你还缺哪些能力？

## H. 前端与部署

- [ ] `ref` / `computed` / `axios` 怎么解释？
- [ ] Vue Router base 为什么重要？
- [ ] GitHub Pages、Render、Neon 各自管什么？
- [ ] CORS 是什么？
- [ ] 线上 404、空白、数据库连接失败分别怎么排查？

## 诊断规则

```text
0-10 个过：先看 00 项目全貌和 08 总复习
11-20 个过：按错题回对应笔记，重点补 RAG / 任务引擎 / 部署
21-30 个过：进入模拟面试题，练表达和追问
```

## 最后提醒

面试官想看到的不是“全都会”，而是“遇到不会的知道怎么拆”。
把每个模块都讲成一个故事：

> 问题 → 拆解 → 实现 → 结果 → 升级方向。
