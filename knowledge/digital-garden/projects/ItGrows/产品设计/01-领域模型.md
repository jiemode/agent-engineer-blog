# 设计领域模型（设计数据关系）是项目的第一步

要实现的工作流目前就是：

```
今天学了FastAPI

        │

        ▼

写一点学习笔记

        │

        ▼

AI帮助整理

        │

        ▼

自动生成Blog

        │

        ▼

保存到Career OS
```

结束。

没有第二个功能。

第一版只有三张核心表

```
Project
```

记录：

```
Founder OS

AI Resume

AI Agent

...
```

---

```
Conversation
```

记录：

```
标题

开始时间

结束时间

属于哪个 Project
```

---

```
Knowledge
```

记录：

```
标题

正文

标签

来源 Conversation

所属 Project
```
