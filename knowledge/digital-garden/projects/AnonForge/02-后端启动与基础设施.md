# 后端启动与基础设施

你之前学过“到底谁把这些模块初始化了”，现在看真实答案。

## 入口：main.py

```python
@asynccontextmanager
async def lifespan(_: FastAPI):
    await ensure_default_admin()   # 启动时保证有个默认管理员
    yield

def create_app() -> FastAPI:
    app = FastAPI(title=..., lifespan=lifespan)
    app.include_router(api_router)          # 挂上所有业务路由
    app.mount("/oss", StaticFiles(...))     # 用户上传文件静态暴露
    return app

app = create_app()
```

关键点：

- `lifespan` 是“启动时组装世界”的官方位置。
- 数据库连接不是在这里显式建的，而是**模块导入时**由 `core/database.py` 建好引擎和会话工厂。
- `api_router` 本身也是一个 APIRouter，带 `/api` 前缀，再把各个业务 Router 挂进来。这是“总传话筒 → 分传话筒”的层级。

## 配置：core/config.py

`Settings` 是一个 dataclass，所有字段都来自环境变量：

```python
db_host: str = field(default_factory=lambda: os.getenv("DB_HOST", "127.0.0.1"))
```

配套工具函数把字符串安全转成类型：

```
_env_bool      →  "true"/"yes" 这类字符串转 bool
_env_int_tuple →  "1,2,3" 转 (1, 2, 3)
_env_str_tuple →  "a,b" 转 ("a", "b")
```

为什么不用 pydantic-settings？不重要。重要的是这个模式：

> 配置是“外部注入的真相”，代码永远不硬编码密钥、端口、路径。

（真实历史里曾经有人把云凭据硬编码进 config 默认值并提交进 git，被审查报告判为 P0 安全事故。这就是教训。）

## 数据库：core/database.py

```python
engine = build_engine()                          # async engine
async_session_maker = async_sessionmaker(...)    # 会话工厂

async def get_session():
    async with async_session_maker() as session:
        yield session                             # FastAPI 依赖
```

面试必答点：

- 为什么引擎是全局单例？数据库连接昂贵，要连接池复用。
- 为什么 `get_session` 是依赖？每个请求拿到独立会话，事务边界清晰。
- `expire_on_commit=False`：commit 后对象还能继续读，避免“已过期”惊吓。
- SQLite 与 PostgreSQL 通过 `build_database_url` 切换，开发/生产无痛迁移。

## 类视图路由：routers/base.py

项目没有用函数式路由满天飞，而是做了一个轻量“类视图”：

```python
class TaskView(BaseView):
    router_prefix = "/tasks"

    @route("/", methods=["GET"])
    async def list_tasks(self, ...): ...
```

`BaseView.__init__` 自动：

```
扫描类方法上的 __route_config__ → 注册进 APIRouter → 实例本身可调用返回 router
```

好处：

- 同类接口收拢在一个类里，可读性高。
- 通过继承复用“公共中间件、异常转换”逻辑。
- 没有引入 Flask/DRF 那种重框架，几行代码就够。

## 中间件：middlewares/common.py

两个“依赖型中间件”：

```python
async def request_duration_middleware(request):
    start = perf_counter()
    yield                                # 交还控制权给路由
    request.state.request_duration_ms = ...

async def jwt_auth_middleware(request, credentials=Depends(http_bearer)):
    payload = await decode_token(credentials.credentials, ...)
    request.state.current_user_public_id = payload["sub"]
```

注意这里用的是 FastAPI 的 `Depends` 而不是 WSGI middleware。它比传统中间件更贴近依赖注入，还能把结果写进 `request.state` 给下游使用。

## Windows 事件循环陷阱

`main.py` 和 `sitecustomize.py` 里都有同一句话：

```python
asyncio.set_event_loop_policy(asyncio.WindowsSelectorEventLoopPolicy())
```

原因是 Psycopg 的异步连接与 Windows 默认 ProactorEventLoop 不兼容，而 Selector 循环兼容性更好。这就是“工业项目会处理你教程里永远碰不到的环境坑”的典型例子。

## 面试怎么答“FastAPI 启动流程”

```
uvicorn 加载 app.main:app
  → 导入时执行 core.config / core.database / 各 router 模块
  → create_app() 组装 FastAPI 实例
  → lifespan 启动：ensure_default_admin
  → 开始监听
请求来了 → 中间件链 → 路由 → Service → Repository → 数据库
```

把“模块导入期”和“应用启动期”分开讲，是加分项。
